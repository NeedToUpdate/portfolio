This Python tool uses [Eel](https://pypi.org/project/Eel/) to render a GUI for the script. The GUI is made with Handlebars templates + SCSS, and uses gulp and Babel to compile them down to basic HTML/CSS. It uses a model I found online to remove the backgrounds.

</MediaRow>

<MediaRow
  src="/images/legacy/image-tools/02.webp"
  alt="Two folders side by side: three input photos on the left, and the same three with their backgrounds removed on the right"
  side="right"
>

It's quite fast, can use both CPU and GPU depending on the machine you're on, and is able to convert files between PNG, JPG and WebP, compress, resize, and remove EXIF data.

Check it out on my GitHub. There's even a compiled Windows binary in the releases tab!
