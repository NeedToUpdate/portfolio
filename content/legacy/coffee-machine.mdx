I have a [DeLonghi coffee maker](https://www.delonghi.com/en-us/magnifica-s-smart-cappuccino-maker-ecam23270s/p/ECAM23270S), which I bought refurbished for $400. It requires you to push 2 buttons: the "on" button, and the "brew" button about 40 seconds after.

Now, why spend 40 seconds doing a task when you can spend 2 weeks automating it?

<MediaRow
  src="/images/legacy/coffee-machine/02.webp"

>

First we measure the coffee machine, and create the model.

</MediaRow>

<MediaRow
  src="/images/legacy/coffee-machine/03.webp"
  alt="The bracket in the slicer, with supports and the estimated print time"
  side="right"
>

Then we 3D print it!

</MediaRow>

<MediaRow
  src="/images/legacy/coffee-machine/04.webp"
  alt="Two printed versions of the grey bracket side by side on a cutting mat"
  side="left"
>

Then we realize it doesn't work and fix the issues.

Then do that one more time.

(The first time the buttons were off and the arm was too thin. The second time the arm attachment was loose, so I had to make it one piece.)

</MediaRow>

<MediaRow
  src="/images/legacy/coffee-machine/05.webp"
  alt="An ESP32 on a protoboard with a small OLED screen, wired to a blue hobby servo"
  side="right"
  size="third"
>

Then we create a small device using an ESP32 that powers a servo.

</MediaRow>

<MediaRow
  src="/images/legacy/coffee-machine/06.webp"
  alt="A drawCoffeeCup function that draws a coffee cup on the OLED screen with line and pixel calls"
  side="left"
>

We then write some code to draw a coffee cup pixel by pixel!

</MediaRow>

<MediaRow
  src="/images/legacy/coffee-machine/07.webp"
  alt="The finished bracket mounted on the coffee machine, with the screen showing the time and the next brew"
  side="right"
>

And now we have a fresh cup ready to drink at 6:00 am without having to spend 40 seconds pushing buttons. So much extra time to sleep!

</MediaRow>
