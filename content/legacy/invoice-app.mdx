A client of mine wanted an easier way to create a simple invoice form, and wanted to be able to do it from many devices. A web app is the perfect way, as it can be accessed from any device with a modern browser.

The form allows you to write your info, your client's info, and add a logo.

</MediaRow>

<MediaRow
  src="/images/legacy/invoice-app/02.webp"
  alt="The form filled in with a logo and two line items, showing that it is saved to the browser and to the cloud"
  side="right"
  size="third"
>

You can then save the info to localStorage, so next time you open the site it will autofill for you. Or you can save it to the cloud (a dockerized MongoDB instance), so you can access it from anywhere with the same name and password.

The info in the backend is encrypted using your password, and your password is never stored in plaintext. I followed security best practices here, so your info is safe.

</MediaRow>

<MediaRow
  src="/images/legacy/invoice-app/03.webp"
  alt="The generated PDF invoice, with the logo, both addresses, two line items and a total of $200.00"
  side="left"
>

The web app uses pdfkit in the backend to create the PDF. The whole tech stack is Next.js + Tailwind CSS + MongoDB. Component testing and integration testing are done with Cypress. It's all in a Docker container, so deploying is just a simple `docker-compose up`. When I wrote this, it was deployed on one of my VPS machines.

</MediaRow>
